# Baozi Store

Java 17, Maven, Spring Boot, JPA e H2.

Execute `mvn spring-boot:run` na raiz. Importe Baozi.postman_collection.json no Postman e execute as requisições na ordem apresentada, uma por vez. Os IDs são armazenados automaticamente após cada POST. Faça os prints antes de excluir. O banco fica em data/ (não versionado).
